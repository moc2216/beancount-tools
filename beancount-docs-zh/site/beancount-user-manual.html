Beancount 用户手册

这是所有与 Beancount 相关的文档的顶级页面。

http://furius.ca/beancount/doc/index

用户文档

命令行记账的背景：一篇说明性文档，解释了什么是命令行记账，我为什么这样做，并通过一个简单的例子说明我如何操作。请将其作为入门阅读。

复式记账法：对复式记账法的温和介绍，其术语与命令行记账系统所做的假设和简化相兼容。

安装 Beancount：在您的计算机上下载和安装的说明，以及软件发布信息。

运行 Beancount 并生成报告：如何运行 Beancount 可执行文件并生成 report。本文包含面向 Beancount 用户的技术信息。

Beancount 入门：解释如何创建、初始化和组织输入文件的基本知识，以及声明 account 和添加 pad 指令的过程。

Beancount 语言语法：带有示例的语言语法完整描述。这是 Beancount 语言的主要参考。

Beancount 选项参考：对所有可能选项值的描述和解释。

精度与容差：transaction 和 balance assertion 允许从上下文中推断出的少量不精确性（tolerance）。本文档解释了其工作原理。

Beancount 查询语言：对 bean-query 命令行客户端工具的高级概述，该工具允许您从 Beancount 账本文件中提取各种数据表。

Beancount 速查表：单页“速查表”，总结了 Beancount 语法。

库存如何工作：解释库存、其表示方式，以及 lot 如何与库存中持有的头寸进行匹配的详细信息。这是阅读交易文档的预备知识。

导出您的投资组合：如何将您的投资组合导出到外部投资组合跟踪网站。

教程与示例：一个现实的示例账本文件，包含假设的 Beancount 用户几年的财务生活。这可用于测试 Beancount，查看其 report 或 Web 界面的样子。这可以快速让您了解使用 Beancount 能获得什么。

Beancount 邮件列表：特定于 Beancount 的问题和讨论发生在那里。相关的还有 Ledger-CLI 论坛，其中包含更多通用讨论，并作为命令行记账主题的元列表。

Beancount 历史与致谢： 描述 Beancount 的开发历史，并向其贡献者致谢。

Beancount 与 Ledger 及 HLedger 的比较：命令行记账系统之间的定性功能比较。

在 Beancount 中获取价格：如何使用 Beancount 的工具获取和维护您资产的 price 数据库。

导入外部数据：描述从金融机构可下载的外部文件导入数据的过程，以及 Beancount 提供的用于自动化部分工作的工具和库。

食谱与示例

这些文档展示了如何使用复式记账法来完成特定任务。请利用这些文档来培养对如何构建你的 account 结构的直觉。

命令行记账食谱：关于如何记录各种不同类型 financial transaction 的示例。这无疑是建立对如何最佳使用复式记账法直觉的最好方式。

使用 Beancount 进行交易：对交易损益（P/L）的解释，以及如何使用 Beancount 处理各种 investment 和交易场景的实例。这是食谱的补充。

Beancount 中的股票归属：一个示例，展示了如何处理限制性股票单位（RSU）以及科技公司和初创公司常见的归属事件。

使用 Beancount 分摊费用：一个现实且详细的示例，展示了如何使用复式记账法与他人分摊旅行或项目的费用。

我们如何分摊费用：对一种持续系统的更详细描述，该系统用于 (a) 在双方都做出贡献的伴侣之间分摊费用，以及 (b) 向拥有自己账本的具体项目（我们的儿子）分摊费用。这描述了我们真实的系统。

医疗费用（未完成）：一份尚未完全完成的文档，解释了如何处理美国网络内和网络外提供者的医疗费用序列。

追踪医疗索赔：一个示例结构，用于追踪网络外心理治疗课程，包括自付费用、医疗索赔以及针对未覆盖部分的关联 HSA 报销。

计算投资组合回报：如何从 Beancount 账本中计算投资组合回报。这描述了在实验脚本中完成的工作，以及提取正确数据所涉及的过程。

开发者文档

Beancount 脚本与插件：一份指南，介绍如何编写脚本以在内存中加载账本内容并处理 directive，以及如何编写插件来转换它们。

Beancount 设计文档：关于程序架构和设计选择、代码约定、不变量及方法论的信息。如果你想获得更深入的理解，请阅读此文档。

LedgerHub 设计文档：在 beancount.ingest 中实现的导入工具和库的设计与架构。这曾是一个名为 LedgerHub 的独立项目（现已停止维护），其有用部分最终被整合进了 Beancount。这是略显过时的原始设计文档。

源代码：Beancount 源代码的官方仓库自 2020 年 5 月起位于 Github。（2008 年至 2020 年 5 月期间托管在 Bitbucket 上）。

外部贡献：一份列表，列出了其他人制作并分享的、基于 Beancount 库构建的插件、导入器及其他代码。

增强提案与讨论

我偶尔会撰写增强提案，以便在推进工作之前整理和总结我的想法，并向其他用户征求反馈。这是了解我计划添加哪些功能、了解详细工作原理，或与其他类似软件（如 Ledger 或 HLedger）进行比较差异的良好材料。

关于库存记账改进的提案：一份提案，概述了 Ledger 和 Beancount 在库存记账方面的现状，以及一种更好的方法，该方法将支持平均成本记账并在不计算佣金的情况下计算资本利得。

Beancount 中的结算日期：关于结算日期或辅助日期如何在 Beancount 中使用，以及它们在 Ledger 中如何使用的讨论。

Beancount 中的余额断言：对 Beancount 和 Ledger 中执行 balance assertion 的不同语义的总结，以及一项扩展 Beancount 语法以支持更复杂断言的提案。

使用 Beancount 进行基金会计：关于基金会计以及如何最好地使用 Beancount 在单个账本中跟踪多个基金的讨论。

Beancount 中的舍入与精度：关于余额检查中重要的舍入和精度问题的讨论，以及一项推断所需精度的更好方法的提案。（已实现）
